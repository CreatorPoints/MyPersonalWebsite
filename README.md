## How to run it locally?
Why do you need to run locally? anyways if you really need it, open your terminal and run:
```
git clone https://github.com/CreatorPoints/MyPersonalWebsite
cd MyPersonalWebsite
python -m http.server 8080
```
Lets go! now headup to your browser and type:
```
http://localhost:8080
```
and tada! my portfolio page now running locally!
